# 🌱 MandiMate – Smart Agriculture

## 📌 About
MandiMate is a web application that helps farmers compare agricultural market prices and choose a suitable mandi for selling their crops.

## 🎯 Objective
To help farmers make better selling decisions by comparing market prices, transportation costs, and estimated returns.

## ✨ Features
- Crop selection and quantity input
- Mandi price comparison
- Revenue and cost calculation
- Best mandi recommendation
- Market comparison chart
- Print report
- Optional live market data integration

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Data.gov.in API (optional)

## 🚀 How to Run
1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.

## 🔮 Future Scope
- Live market prices
- Route-based transport cost calculation
- Weather updates
- Multiple language support
