# 🌱 MandiMate
### Smart Agricultural Market Intelligence & Dispatch Optimizer

## 📌 About the Project
MandiMate is a web-based agricultural market intelligence system designed to help farmers make informed decisions about where and when to sell their crops.

It compares market prices, estimates transportation expenses and spoilage losses, forecasts prices for the next seven days, and recommends a suitable mandi and dispatch time.

## 🎯 Problem Statement
Farmers can experience losses when they sell their produce without considering market price differences, transport costs, changing demand, weather conditions, and crop perishability.

MandiMate aims to reduce uncertainty by comparing estimated returns across markets and recommending a suitable selling strategy.

## ✨ Features
- Crop selection: Tomato, Onion, Potato, and Wheat.
- Comparison of five markets: Pune, Nashik, Mumbai, Satara, and Ahmednagar.
- Seven-day price forecasting.
- Estimated transportation and fuel costs.
- Crop spoilage and transit-loss estimation.
- Consideration of rain, missing price records, and market closures.
- Risk-adjusted market recommendations.
- Estimated net-return comparison and visual charts.
- Optional Data.gov.in API integration for available current market prices.
- Printable dispatch recommendation report.

## 🛠️ Technologies Used

## 🚀 How to Run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `mandi_mate.html` in a web browser.
4. Enter the crop and transportation details.
5. Click **Find Best Mandi**.
6. Review the market comparison, price forecast, costs, and dispatch recommendation.

The application works in demonstration mode without an API key.

## 📊 How It Works
1. Collects or generates market price history.
2. Cleans missing and unusual price records.
3. Forecasts prices for the next seven days.
4. Estimates transportation expenses, spoilage, and other costs.
5. Compares possible markets and selling dates.
6. Displays the recommended option based on estimated risk-adjusted returns.

## ⚠️ Limitations
- Demonstration mode uses simulated price history.
- Live price integration depends on API access and available matching records.
- Distances and transportation costs are estimates, not verified quotations.
- Forecasts are estimates and do not guarantee future prices or profits.
- Farmers should verify current market prices and transport costs before dispatch.
